# Моя статистика / My stats

Каждый человек видит **свою** статистику без дополнительных прав. Администратор может смотреть и чужую.

## Инструменты

| Вопрос | Инструмент |
|---|---|
| Сколько диалогов, исходы, средние оценки за период | `stats_me_overview` |
| Оценки по критериям, примеры сообщений с замечаниями | `stats_me_quality` |
| Динамика по неделям и месяцам | `stats_me_trend` |
| Список моих диалогов с исходом и оценкой | `dialogs_mine` |
| Чужая статистика (админ или строка «видеть · менеджер») | `stats_executor_overview`, `stats_executor_quality` |

## Как отвечать

1. Начните с `stats_me_overview` за нужный период (по умолчанию неделя). Если ответ говорит `linked: false` — аккаунт ещё не привязан к исполнителю: скажите об этом и попросите администратора привязать вас в разделе «Команда». Не подставляйте чужие цифры.
2. Для вопроса «что улучшить» возьмите `stats_me_quality` и покажите 2–3 конкретных замечания с примерами, потом `stats_me_trend`, чтобы видеть, растёт ли показатель.
3. Контакты клиентов приходят замаскированными, пока у токена нет права «контакты». Не пытайтесь восстановить маску и не просите её снять.
4. Цифры называйте с периодом и источником («за последние 7 дней, по вашим 14 диалогам»). Не делайте выводов о людях, если данных мало, — скажите, что выборка маленькая.
5. Без стыжения: оценки — повод для разговора о росте, а не для упрёков.
