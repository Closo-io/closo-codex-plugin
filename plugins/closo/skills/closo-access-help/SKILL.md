# Нет доступа / Access help

Права в Closo зависят от роли, таблицы доступа администратора и настроек организации. Не пытайтесь обойти отказ другим инструментом.

1. Вызовите `access_explain` с именем инструмента (и объектом: `resource_type` — `funnel`, `agent` или `executor`, и `resource_id`). Он ответит кодом и понятной причиной:
   - `access.no_grant` — нет права ни по роли, ни по строке таблицы;
   - `access.denied` — запрещено строкой таблицы;
   - `access.paused` — MCP приостановлен для организации или для вас;
   - `access.module_disabled` — модуль выключен;
   - `access.cabinet_only` — это действие только в кабинете.
2. Скажите человеку, что именно попросить: «Попросите администратора выдать право «менять» на воронку «Салон» в разделе «Доступ MCP» кабинета».
3. Ответ «нет такого объекта» не различает «нет» и «не ваш»: это защита, не ошибка. Не перебирайте номера.
4. Если не хватает прав токена (`insufficient_scope`), клиент предложит войти заново с нужными правами — согласитесь только если человек этого хочет.
5. Если нужен ответ на вопрос «что у меня есть» — `access_me`.
