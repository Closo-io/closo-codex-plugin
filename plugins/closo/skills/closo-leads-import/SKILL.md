# Импорт лидов / Lead import

Импорт создаёт пустые диалоги из лидов CRM. Это долгое дело, и запускает его только человек.

## Порядок

1. **Оценка.** `lead_import_preview` с интеграцией и настройками источника: только числа (всего, уже связаны, к импорту), без персональных данных. Покажите их человеку.
2. **Запуск.** `lead_import_start`. Сервер ответит вопросом человеку («Запустить импорт?») — это ожидаемо, дождитесь его решения. Одно активное задание на интеграцию.
3. **Задача.** Если ваше приложение поддерживает задачи MCP, ответом будет задача (`taskId`): опрашивайте `tasks/get` с паузой `pollIntervalMs`, пока статус не станет `completed`, `failed` или `cancelled`. Без поддержки задач — опрашивайте `lead_import_get` по `job_id`.
4. **Прогресс.** Сообщайте обработано/всего, созданные диалоги, пропущенные и ошибки. Не заваливайте человека каждым опросом: раз в минуту достаточно.
5. **Отмена.** По просьбе — `tasks/cancel` или `lead_import_cancel`. Созданные диалоги остаются; текущая пачка (до 100 лидов) доработает.

Ручку задачи храните: после обрыва связи опрос продолжается с тем же `taskId`.
